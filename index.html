Instalando no Android

Siga estas etapas para instalar o aplicativo.

03 ETAPAS
01

Baixe o aplicativo

Clique no botão de download abaixo para baixar o arquivo APK oficial do PEG.

↓
PEG.apk Aplicativo para Android

02

Abra o arquivo baixado

Acesse seus downloads e toque no arquivo APK. Caso o Android solicite, autorize a instalação de aplicativos dessa fonte.

Dica: autorize somente o arquivo baixado pelo link oficial do PEG.

IPHONE · IOS

Instalando no iPhone

Adicione o PEG diretamente à sua tela inicial.

04 ETAPAS
01

Abra o Safari

No iPhone, abra o navegador Safari e acesse o site oficial do PEG pelo botão abaixo.

02

Toque em Compartilhar

No Safari, procure o ícone de compartilhamento (um quadrado com uma seta para cima).

□↑
03

Adicionar à Tela de Início

No menu, selecione "Adicionar à Tela de Início". Dependendo da versão do iOS, a opção pode aparecer dentro de "Mais".

⊞ Adicionar à Tela de Início ›
04

Confirme a instalação

Toque em "Adicionar". O ícone do PEG aparecerá na tela inicial do seu iPhone.

↗ Abrir PEG no Safari

No iPhone, este método adiciona a versão web do PEG à tela inicial, sem precisar da App Store.

PRECISA DE AJUDA?

Dúvidas frequentes.

Respostas para os problemas mais comuns.

O PEG é gratuito? +

Sim! A plataforma PEG é gratuita para os estudantes.

O aplicativo funciona no iPhone? +

Sim. Você pode acessar o PEG pelo Safari e adicioná-lo à tela inicial.

Não consigo instalar no Android. +

Confira se o download terminou e se o Android permitiu a instalação do arquivo APK oficial. Se continuar com problemas, utilize o site do PEG.

Preciso criar uma conta? +

Para utilizar as funcionalidades internas, você precisa entrar ou cadastrar sua conta.
